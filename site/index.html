Методология

pipeline
  1. Чтение snps.annotations.txt: позиции, REF, ALT.
  2. Чтение samples.qc.txt: QC, гаплогруппа, missing/private mutations, ALIGN-артефакты.
  3. Формирование ожидаемого AMP-набора: annotation positions минус ALIGN positions.
  4. Сверка с кураторской таблицей from_AMP.csv.
  5. Генерация sanitized статического HTML без JavaScript и внешних CDN.
  6. Графики выполняются как inline SVG для снижения surface area.
  7. Pre-deploy security/privacy проверка через predeploy_check.py.
